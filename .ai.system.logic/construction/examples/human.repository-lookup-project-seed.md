# Repository lookup project seed

The candidate retains request and response contracts and three validation cases by pinned reference. A receiving project establishes its own source resolution, authority, and disclosure rules.

[Source JSON](ai.repository-lookup-project-seed.json)

Record identity · kind `project_seed_example` · version `1.0` · mode `reference_only`

## How to use this record

Use this as an illustrative extraction of the exchange for a receiving project.

The retained contracts supply the rules. The three paired examples supply validation cases. Resolve them at their pinned revisions, repeat the cases, and establish local authority and disclosure before adoption.
